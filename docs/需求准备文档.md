## 1. 项目概述

搭建一个面向雅思备考的学习网站。用户可以在线练习写作、背单词、做阅读，并借助 AI 生成范文、按雅思四项评分标准批改作文。

第一版只做 MVP（最小可用产品）：把「登录 → 选题写作 → AI 范文 / 批改」这条核心链路跑通，同时带上词汇和阅读两个基础模块。听力、口语放到后续版本。

## 2. 已确认的技术选型

| 层次 | 选型 | 说明 |
|------|------|------|
| 前端 | Vue 3 + TypeScript + Vite | 官方脚手架 |
| 状态 / 路由 | Pinia + Vue Router | 登录态、页面跳转 |
| UI | Element Plus | 中文文档、组件齐全 |
| 图表 | ECharts | 作文批改四维雷达图 |
| HTTP | Axios | 统一拦截 JWT、错误提示 |
| 后端 | Java 21 + Spring Boot 3.3+ | 当前 LTS |
| ORM | MyBatis-Plus | SQL 可控，国内资料多 |
| 认证 | Spring Security + JWT | 无 Session |
| AI | Spring AI + DeepSeek | OpenAI 兼容接口，国内直连 |
| 接口文档 | Knife4j | 访问地址 `/doc.html`，不用 Swagger UI |
| 库表版本 | Flyway | 启动时自动建表、灌种子数据 |
| 数据库 | 本地 MySQL 8.x | 账号 `root` / 密码 `root`，库名 `alice_learn` |

**明确不做（第一版）：**

- 听力、口语、语音识别
- Docker 编排 MySQL（直接连本机）
- SpringDoc / 原生 Swagger UI
- 支付、会员体系、后台运营管理系统

## 3. MVP 功能范围

### 3.1 用户系统

- 注册（用户名 + 密码 + 邮箱）
- 登录，返回 JWT
- 获取当前用户信息（含目标分数）
- 未登录访问业务接口时跳转登录页

### 3.2 写作模块（核心）

- 题库列表：分页、按 Task 1 / Task 2 筛选
- 题目详情：题干、难度、可选配图
- 在线写作：草稿保存、字数统计、提交
- **AI 生成范文**：根据题目描述流式输出（打字机效果）
- **AI 批改**：按雅思四项打分并给出逐句建议
  - TA（Task Achievement / Task Response）
  - CC（Coherence and Cohesion）
  - LR（Lexical Resource）
  - GRA（Grammatical Range and Accuracy）
- 批改报告页：总分、四维雷达图、修改建议列表

### 3.3 词汇模块

- 词库浏览（分页、按分类筛选）
- 加入 / 移除生词本
- 记忆卡片：按 `next_review_at` 做简化版间隔重复（熟悉度 0~5）
- 第一版词库规模：**200～300 个词**（后续可再扩充）

### 3.4 阅读模块

- 文章列表 / 详情
- 题目作答、提交后自动判分
- 显示对错与解析

### 3.5 个人中心

- 作文记录、批改历史
- 阅读练习历史

## 4. 系统架构

```
浏览器 (Vue 3)
    │  REST + JWT
    │  SSE（AI 流式输出）
    ▼
Spring Boot 后端
    ├── MySQL (alice_learn)
    └── Spring AI → DeepSeek (https://api.deepseek.com)
```

**数据流简述：**

1. 用户登录后，前端在请求头携带 JWT。
2. 写作页点击「AI 生成范文」：后端调 DeepSeek，通过 SSE 把文本一块一块推给前端。
3. 用户提交作文后点击「AI 批改」：后端要求模型返回结构化 JSON（四维分数 + 建议），落库后再返回前端。
4. 每次 AI 调用记录 token 消耗，方便排查和后续控成本。

## 6. 数据库设计

连接信息：

- JDBC：`jdbc:mysql://localhost:3306/alice_learn?createDatabaseIfNotExist=true&useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai`
- 账号 / 密码：`root` / `root`
- 表结构与种子数据由 Flyway 在应用启动时自动执行

### 6.1 表清单

| 表名 | 用途 |
|------|------|
| `user` | 用户账号、目标分数 |
| `writing_task` | 写作题库（Task1 / Task2） |
| `essay` | 用户作文（草稿 / 已提交 / 已批改） |
| `essay_review` | AI 批改结果 |
| `word` | 词库 |
| `user_word` | 用户生词本 + 复习计划 |
| `reading_passage` | 阅读文章 |
| `reading_question` | 阅读题目 |
| `user_answer` | 用户答题记录 |
| `ai_call_log` | AI 调用与 token 统计 |

### 6.2 字段说明

**user**

| 字段 | 说明 |
|------|------|
| id | 主键 |
| username | 登录名，唯一 |
| password | BCrypt 加密 |
| email | 邮箱 |
| target_score | 目标分数，如 6.5 |
| created_at | 注册时间 |

**writing_task**

| 字段 | 说明 |
|------|------|
| id | 主键 |
| task_type | `TASK_1` / `TASK_2` |
| title | 题目标题 |
| description | 题目描述（给 AI 和用户看） |
| image_url | Task 1 图表配图，可空 |
| difficulty | 难度 |

**essay**

| 字段 | 说明 |
|------|------|
| id | 主键 |
| user_id | 作者 |
| task_id | 对应题目 |
| content | 作文正文 |
| word_count | 字数 |
| status | `DRAFT` / `SUBMITTED` / `REVIEWED` |
| created_at | 创建时间 |

**essay_review**

| 字段 | 说明 |
|------|------|
| id | 主键 |
| essay_id | 对应作文 |
| overall_score | 总分（四项平均，雅思 0.5 步进） |
| ta_score / cc_score / lr_score / gra_score | 四维分数 |
| feedback_json | 逐句修改建议（JSON 数组） |
| sample_essay | 可选：同题范文摘要 |
| created_at | 批改时间 |

**word / user_word**

- `word`：单词、音标、释义、例句、分类（雅思核心 / 学术等）
- `user_word`：熟悉度 0~5、下次复习时间 `next_review_at`

**reading_passage / reading_question / user_answer**

- 文章正文、难度
- 题型、题干、选项 JSON、标准答案、解析
- 用户答案、是否正确

**ai_call_log**

- 场景：`GENERATE_SAMPLE` / `REVIEW_ESSAY`
- prompt_tokens、completion_tokens

### 6.3 种子数据（第一版）

- 写作题：10~20 道（Task 1 / Task 2 都有）
- 词汇：**200～300 个词**
  - 来源：以公开学术词表 Academic Word List（AWL）高频子集为底，按话题（教育、环境、科技、健康、社会等）整理
  - 字段：单词、音标、中文释义、例句、分类
  - 不爬取商业 App、不整本录入有版权的雅思词汇书
  - 写入 Flyway 种子脚本，应用启动时自动导入
- 阅读：2~3 篇文章及配套题目

## 7. 后端开发计划

### 阶段 1：骨架 + 认证

1. Maven 初始化 Spring Boot 3 项目，Java 21。
2. 依赖：web、validation、mybatis-plus、mysql、flyway、spring-security、jjwt、spring-ai-openai-starter、knife4j-openapi3-jakarta-spring-boot-starter。
3. DeepSeek 走 OpenAI 兼容接口，`base-url` 指向 `https://api.deepseek.com`。
4. 通用设施：`Result<T>` 统一响应、全局异常、分页封装。
5. Spring Security：BCrypt、JWT 过滤器；放行 `/api/auth/**` 以及 Knife4j 路径（`/doc.html`、`/webjars/**`、`/v3/api-docs/**`）。
6. 接口：注册、登录、获取当前用户。
7. 文档地址：`http://localhost:8080/doc.html`。

### 阶段 2：写作模块（核心）

1. 题库列表分页、详情。
2. 作文草稿保存、提交（字数校验）。
3. `AiWritingService`：
   - `generateSample(taskId)`：固定雅思范文 Prompt，SSE 流式返回。
   - `reviewEssay(essayId)`：要求模型按 TA/CC/LR/GRA 输出结构化 JSON，用 Spring AI 的 `BeanOutputConverter` 映射为 Java 对象，写入 `essay_review`。
4. API Key 通过环境变量 `DEEPSEEK_API_KEY` 注入，不写进代码。
5. 每次调用写入 `ai_call_log`；超时 / 失败返回明确错误码，前端可重试。

### 阶段 3：词汇 + 阅读

1. 词汇分页、生词本增删、待复习卡片列表。
2. 阅读文章列表 / 详情、提交答案自动判分、解析。
3. Flyway 导入 200～300 个雅思核心词（AWL 高频子集 + 话题分类）。

## 9. 接口约定（草案）

统一前缀：`/api`  
统一响应：`{ "code": 0, "message": "ok", "data": ... }`

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| POST | `/api/auth/register` | 注册 | 否 |
| POST | `/api/auth/login` | 登录，返回 token | 否 |
| GET | `/api/auth/me` | 当前用户 | 是 |
| GET | `/api/writing/tasks` | 题库分页 | 是 |
| GET | `/api/writing/tasks/{id}` | 题目详情 | 是 |
| POST | `/api/writing/essays` | 保存草稿 / 提交 | 是 |
| GET | `/api/writing/essays/{id}` | 作文详情 | 是 |
| GET | `/api/writing/essays/{id}/sample` | SSE 生成范文 | 是 |
| POST | `/api/writing/essays/{id}/review` | AI 批改 | 是 |
| GET | `/api/vocab/words` | 词库分页 | 是 |
| POST | `/api/vocab/notebook` | 加入生词本 | 是 |
| DELETE | `/api/vocab/notebook/{wordId}` | 移出生词本 | 是 |
| GET | `/api/vocab/review` | 待复习卡片 | 是 |
| GET | `/api/reading/passages` | 文章列表 | 是 |
| GET | `/api/reading/passages/{id}` | 文章 + 题目 | 是 |
| POST | `/api/reading/answers` | 提交答案 | 是 |
| GET | `/api/me/essays` | 我的作文记录 | 是 |

编码阶段可按实现微调，以 Knife4j 文档为准。
